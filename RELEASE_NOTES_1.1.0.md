# Surface Touch Mediaplayer 1.1.0

Diese Version verbessert die Bedienung auf hochauflösenden Touch-Geräten. Sprachneutrale Symbole ersetzen die verbliebenen Texttasten; Tooltips, Statusmeldungen, Dialoge und Fehlermeldungen wählen automatisch Deutsch oder Englisch anhand der Windows-Anzeigesprache.

Die Anwendung besitzt nun eine einheitliche große Touch-Fensterleiste. Die doppelte Windows-Titelleiste entfällt, das Fenster bleibt verschiebbar und an den Rändern skalierbar, und Maximieren lässt die Taskleiste sichtbar. Transporttasten stehen links; Zufall, Wiederholen, Vollbild und Lautstärke sind rechtsbündig gruppiert.

**Download:** `Surface Touch Mediaplayer.exe` direkt starten oder das ZIP mit deutscher und englischer README sowie MIT-Lizenz herunterladen. Es wird keine Installation benötigt.

**Voraussetzungen:** Windows 10/11 (64 Bit) und 64-Bit-VLC. VLC und seine Plugins sind nicht enthalten. Die Anwendung findet die Standardinstallation, Registry-Einträge oder eine portable Installation im Ordner `VLC` neben der EXE.

**SHA-256 der EXE:** `4A93D96C451438EDF1E53CA8EBDAFAAC95557A834711050383FDAED1872FFF65`

Build und automatisierte Tests wurden erfolgreich ausgeführt. Die EXE ist nicht digital signiert; Windows SmartScreen kann deshalb beim ersten Start eine Warnung anzeigen. Hinweise zur Prüfung und zur Internet-Markierung stehen in der README.

This release improves operation on high-resolution touch devices. Language-neutral icons replace the remaining text buttons; tooltips, status messages, dialogs, and errors automatically use German or English according to the Windows display language.

The application now uses one unified large touch title bar. The duplicate Windows title bar is gone, the window remains movable and resizable at its edges, and maximizing keeps the taskbar visible. Transport controls are on the left; shuffle, repeat, full screen, and volume are grouped on the right.

**Download:** Run `Surface Touch Mediaplayer.exe` directly, or download the ZIP with German and English READMEs and the MIT license. No installation is required.

**Requirements:** 64-bit Windows 10/11 and 64-bit VLC. VLC and its plugins are not bundled. The application detects the standard installation, Registry entries, or a portable installation in a `VLC` folder beside the EXE.

**EXE SHA-256:** `4A93D96C451438EDF1E53CA8EBDAFAAC95557A834711050383FDAED1872FFF65`

The build and automated tests passed. The EXE is not code-signed, so Windows SmartScreen may show a warning on first launch. The README explains checksum verification and the Internet origin marker.
