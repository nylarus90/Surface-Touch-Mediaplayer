# Surface Touch Mediaplayer 1.0.1

Die erste öffentliche Download-Version enthält die Touch-Oberfläche für den lokal installierten 64-Bit-VLC. Die Ton-Taste wurde korrigiert: Sie zeigt den von VLC gemeldeten Stumm-Status und schaltet ihn gezielt um.

**Download:** `Surface Touch Mediaplayer.exe` direkt starten oder das ZIP mit deutscher und englischer README sowie MIT-Lizenz herunterladen. Es wird keine Installation benötigt.

**Voraussetzungen:** Windows 10/11 (64 Bit) und 64-Bit-VLC. VLC und seine Plugins sind nicht enthalten. Die Anwendung findet die Standardinstallation, Registry-Einträge oder eine portable Installation im Ordner `VLC` neben der EXE.

**SHA-256 der EXE:** `F3273A0796EB54B6548F946DAE8AF6A66DDF92633E26FD9A0F6D80780977CD7D`

Build und automatisierte Tests wurden erfolgreich ausgeführt. Die EXE ist nicht digital signiert; Windows SmartScreen kann deshalb beim ersten Start eine Warnung anzeigen.

The first public download includes the touch interface for a locally installed 64-bit VLC. The mute button now reads VLC's actual mute state, applies the requested state explicitly, and displays the matching icon.

**Download:** Run `Surface Touch Mediaplayer.exe` directly, or download the ZIP with German and English READMEs and the MIT license. No installation is required.

**Requirements:** 64-bit Windows 10/11 and 64-bit VLC. VLC and its plugins are not bundled. The application detects the standard installation, Registry entries, or a portable installation in a `VLC` folder beside the EXE.

**EXE SHA-256:** `F3273A0796EB54B6548F946DAE8AF6A66DDF92633E26FD9A0F6D80780977CD7D`

The build and automated tests passed. The EXE is not code-signed, so Windows SmartScreen may show a warning on first launch.
